# CMS Project

## Hướng dẫn chạy Backend

1. Mở thư mục Backend.

2. Mở file CMS.sln bằng Visual Studio 2022.

3. Kiểm tra chuỗi kết nối SQL Server trong appsettings.json.

4. Nhấn F5 để chạy.

Backend sẽ chạy tại:

https://localhost:5001

---

## Hướng dẫn chạy FrontEnd

Mở CMD.

Di chuyển tới thư mục FrontEnd.

```
cd FrontEnd
```

Cài package

```
npm install
```

Chạy project

```
npm start
```

Frontend chạy tại

http://localhost:3000
